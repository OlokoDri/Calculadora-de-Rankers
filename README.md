# 🏆 Calculadora de Rankers

Projeto simples desenvolvido em JavaScript para calcular o nível de um jogador com base na quantidade de vitórias e derrotas.

## 📌 Sobre o projeto

A Calculadora de Rankers recebe a quantidade de vitórias e derrotas de um jogador, calcula o saldo de partidas ranqueadas e exibe o nível correspondente.

O cálculo é feito assim:

```javascript
saldo = vitorias - derrotas

⚔️ Tabela de ranks

-Saldo de vitórias	Rank
-Menor que 10	Ferro
-Entre 11 e 20	Bronze
-Entre 21 e 50	Prata
-Entre 51 e 80	Ouro
-Entre 81 e 90	Diamante
-Entre 91 e 100	Lendário
-Maior ou igual a 101	Imortal
